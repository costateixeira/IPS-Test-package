TestPlan: IPS Server Test Plan (Experimental)

Official URL: http://example.com/fhir/hl7.fhir.uv.ips.test/TestPlan/ips-server-tests Version: 0.1.0
Draft as of 2026-09-20 Computable Name: IPSServerTestPlan

Test plan for the IPS Server actor of HL7 International Patient Summary (IPS) 2.0.1. An IPS Server is a FHIR server acting as an IPS Creator by providing conformant IPS documents in response to FHIR API requests (CapabilityStatement ips-server). Each suite below is a Rule: of the Gherkin feature named by suite.input.file, and each suite.test one of its Scenario: lines, matched by the scenario's identifier. The assertions are the scenario's Then steps, verbatim. The tests declare which specification obligations they cover (9 element obligations across the plan); the coverage matrix is checked mechanically against the specification package.
